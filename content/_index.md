### Unity exploration:
- [steam-multiversion-viewer](https://github.com/jakobhellermann/steam-multiversion-viewer)
  - A tool for viewing contents of steam games at various game versions, with file format introspection
  - VFS for mounting game versions and downloading them on the fly
- [RustyAssetBundleEXtractor](https://github.com/jakobhellermann/RustyAssetBundleEXtractor) - Rust tooling for working with unity files
- [unity-scene-repacker](https://github.com/jakobhellermann/unity-scene-repacker) - Repack unity levels into filtered assetbundles
